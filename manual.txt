

    RENEX POKEY
    ===========
    v1.0
    18 Aug 2026


  A modern, high quality implementation of a POKEY-style sound engine.

  Written by renex. Designed for Game Maker 8.2.


-------------------------------------------------------------------------------

  Pokey?
  ------


  POKEY is a co-processor present in some of Atari's first home consoles. It
  was responsible for reading controller input and, among other things, had
  limited sound output capabilities through 4 builtin programmable sound
  generators using simplistic pulse and noise models. When you think of
  "dat Atari sound doe", that's a POKEY chip in action.

  This extension provides a modern reimplementation of the sound core of the
  POKEY chip, with customizable channel counts, high quality audio output,
  and accurate frequency tuning and stereo panning values, for use in realtime
  sound generation for video games and music applications.


-------------------------------------------------------------------------------

  Instruments
  -----------
  
  
  The POKEY chip has a few different presets for its sound generators. Since
  the goal of this extension is to produce high quality sound rather than to
  perfectly emulate the chip itself, any duplicates or silent instrument
  slots have been removed. Additionally, all instrument types have been pitch
  shifted such that the output pitch matches the set input frequency, and the
  known broken frequency values have not been reproduced. We also supply a
  12.5% duty square wave, which was not originally present as a preset, but is
  frequently used in 'retro' soundscapes which felt relevant to include.
  
  
  Available instrument types:

  pk_pulse (0): Square
  - A standard 50% duty square wave.
  
  pk_p1813 (1): Pulse 18-13 duty
  - This is the POKEY's unique flavor of square wave, with an approximate
    58% duty cycle. Sounds softer than the regular square wave.
  
  pk_p125 (2): Pulse 12.5% duty
  - 12.5% duty square wave. A more open sound, commonly heard on NES games.
  
  pk_poly4 (3): Poly 4
  - A 4-bit polynomial counter. Sounds like a bass instrument.
  
  pk_poly5 (4): Poly 5
  - A 5-bit polynomial counter. A harsh, droning sound.
  
  pk_poly9 (5): Poly 9
  - A 9-bit polynomial counter. Sounds like wind or fire.
  
  pk_poly4_5 (6): Poly 4 -> Poly 5
  - A 4-bit polynomial counter, lowpassed by a 5-bit polynomial counter.
    Sounds like a car engine.

  pk_poly17 (7): Poly 17
  - A 17-bit polynomial counter. Sounds like white noise.


-------------------------------------------------------------------------------

  Function list
  -------------


- pokey_init(samplerate,channels)
  - samplerate: audio sample rate (8000-48000)
  - channels: number of channels (1-32)

    Starts the sound engine with the desired settings.
    The sample rate is limited by the system's capabilities.
    Usually, values between 8000 and 48000 are acceptable.
    The number of channels is the number of unique voices that can be played
    simultaneously, limited between 1 and 32. This limit is not final - just
    let me know if you need more voices for your specific application.


- pokey_update()
    Updates the pokey engine with the latest instrument data.
    Note that is is normally done for you; you only need to call it
    manually if you're f.ex. in a deadlock for a loading screen or a room
    transition.


- pokey_get_chromatic_frequency(note)
  - note: note to convert to hertz
  
    Returns the frequency in Hz of a note on the chromatic scale. The first
    note is A0 (27.5Hz), with 12 notes in an octave. For example, note 48
    (A4, 4 octaves above A0) returns 440 Hz.


- pokey_get_byte_frequency(byte)
  - byte: note id (0-254)
  
    Returns a corrected frequency value of a note byte from 0 to 254 as heard
    in the original POKEY chip with default settings. If you're going for a
    retro aesthetic, using only frequencies returned by this function should
    provide the more authentic Atari sound flavor.


- pokey_get_instrument_name(type)
  - type: instrument id (0-6)

    Returns a string with the name of the selected instrument.


- pokey_sound(channel,type,freq,vol,pan)
  - channel: channel to use (0 - 32)
  - type: instrument id (0 - 6)
  - freq: sound frequency in hz
  - volume: channel volume (0 - 1)
  - pan: channel pan (-1 - 1)

    Starts playing sound in a channel. To stop a channel, set the volume to 0.
    Do note that the maximum frequency that can be played is below half of
    your sample rate, anything too close to it will have "beating" artifacts.
    The available instrument types are identifiable with the pk_ constants.
    More instrument information is available in the "Instruments" section.


- pokey_get_voices()
    Returns the current number of active channels.
    A channel is considered active when frequency and volume are not zero.


- pokey_stop()
    Silences all channels. Calling this function is equivalent to setting the
    volume to 0 on all channels.
